Takeaway: Server rendering gave every product page real HTML for search engines.

Cover: 2

## The problem with client-only rendering

With Create React App, every product page arrived as an empty shell until JavaScript ran. Search engines indexed it slowly and shoppers on slow phones stared at a spinner.

## What Next.js changed

- Product pages render on the server with full HTML and meta tags.
- Static generation for categories that rarely change.
- Built-in image optimisation cut page weight noticeably.

> Server rendering wasn't a nice-to-have. *Search was the product.*

## Would I choose it again?

Yes, for anything where discovery matters. For an internal dashboard behind a login, plain React is still simpler.
